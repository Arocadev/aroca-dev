## ¿Qué es aroca.dev?

Portfolio personal diseñado e implementado desde cero. Reúne todos mis proyectos con contexto real: qué problema resolvía cada uno, qué decisiones tomé y qué aprendí.

Construido con Astro por su rendimiento y su modelo de cero JavaScript por defecto. Desplegado en Vercel con dominio propio.

## Decisiones de diseño

- Fondo `#0d1117` + acento índigo `#818cf8`
- Jerarquía de color en cuatro niveles: `#fff` → `#c8dae8` → `#8aa0b4` → `#5a7080`
- One-page scroll con nav sticky y páginas individuales por proyecto
- Sin frameworks CSS, sin JavaScript innecesario
